# Adversarial Review Prompt v1.0

Your job is to attack the current thesis.

Look for:
- priced-in assumptions;
- contradictory news;
- stale sources;
- sector evidence against the thesis;
- options data that contradicts the directional view;
- liquidity problems;
- alternate causal explanations;
- look-ahead contamination;
- excessive confidence.

Do not create new facts. Flag what needs verification.
Return risks and whether confidence should be reduced.
